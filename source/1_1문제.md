② 둘은 항상 같은 값을 갖는다
③ R²는 단위가 있고 MSE는 단위가 없다
④ MSE는 클수록 좋다

## C. 분류 평가 / 일반화·오버피팅

### 39.

③ 실제 양성 중 맞춘 비율만
④ 오차 제곱 평균

### 40. ★★

② 정확도는 계산할 수 없어서
③ 정확도는 회귀 지표라서
④ 정확도는 항상 0이어서

### 41.

TP(True Positive)의 의미는?

① 실제 양성, 예측 양성
② 실제 음성, 예측 음성
③ 실제 음성, 예측 양성
④ 실제 양성, 예측 음성

### 42. ★

TN(True Negative)의 의미는?

① 실제 양성, 예측 양성
② 실제 음성, 예측 음성
③ 실제 음성, 예측 양성
④ 실제 양성, 예측 음성

### 43.

FP(False Positive)의 의미는?

① 실제 음성인데 양성으로 잘못 예측
② 실제 양성인데 음성으로 잘못 예측
③ 실제 양성을 양성으로 예측
④ 실제 음성을 음성으로 예측

### 44.

FN(False Negative)의 의미는?

① 실제 음성인데 양성으로 예측
② 실제 양성인데 음성으로 잘못 예측
③ 실제 양성을 양성으로 예측
④ 실제 음성을 음성으로 예측

### 45. ★★

정밀도(Precision)의 식은?

① TP/(TP+FP)
② TP/(TP+FN)
③ TN/(TN+FP)
④ (TP+TN)/전체

### 46.

재현율(Recall)의 식은?

① TP/(TP+FP)
② TP/(TP+FN)
③ TN/(TN+FN)
④ FP/(FP+TN)

### 47. ★★

F1-score는 무엇의 조화평균인가?

① 정밀도와 재현율
② MSE와 R²
③ 훈련오류와 테스트오류
④ TP와 TN

### 48. ★★★

교차 엔트로피 손실에 대한 설명으로 옳은 것은?

① 정답에 준 확률이 높을수록 손실이 작아진다
② 정답 확률이 낮을수록 손실도 작아진다
③ 학습이 끝난 뒤 평가에만 쓴다
④ 회귀의 R²와 동일하다

### 49. ★

학습의 최종 목적에 가장 가까운 것은?

① 훈련 데이터 암기
② 새로운 데이터에 대한 일반화된 예측
③ 훈련오류를 무조건 0으로 만들기
④ 모델을 최대한 복잡하게 만들기

### 50.

오버피팅(Overfitting)의 전형적인 현상은?

① 훈련 오류는 낮고 테스트 오류는 높다
② 훈련/테스트 오류가 모두 높다
③ 훈련 오류가 높고 테스트 오류가 항상 0
④ 모델이 너무 단순하다

### 51.

오버피팅이 좋지 않은 이유로 적절한 것은?

② 훈련 데이터 성능이 낮아지기 때문만
③ 항상 계산량이 작기 때문
④ Label이 사라지기 때문

### 52.

언더피팅(Underfitting)의 설명으로 옳은 것은?

① 모델이 지나치게 단순하거나 학습이 부족해 중요한 패턴을 놓친다
② 훈련 데이터 잡음을 지나치게 암기한다
③ 테스트 데이터에만 맞춘다
④ 항상 훈련오류가 0이다

### 53.

① 더 많은 데이터와 테스트 데이터 활용, 모델 선택, 교차검증
② 항상 가장 복잡한 모델 선택
③ 훈련 데이터만 반복 평가
④ 검증 데이터 삭제

### 54.

훈련 오류(Training Error)는?

② 새로운 데이터에서 계산한 오류
③ 검증셋에서만 계산한 오류
④ 교차검증 평균 오류만 의미

### 55.

테스트 오류(Test Error)는?

① 학습에 사용하지 않은 새 관측치에 모델을 적용했을 때의 평균 예측오류
② 훈련 데이터에서의 오차
③ Label이 없는 데이터의 개수
④ 항상 훈련오류와 같다

## D. 검증·교차검증 / 비지도학습

### 58.

검증셋(Validation Set) 접근의 기본 아이디어는?

① 데이터를 훈련셋과 검증셋으로 나누어 학습과 성능 측정을 분리
② 전체 데이터를 항상 훈련에만 사용
③ 검증셋으로 모델을 학습하고 훈련셋으로 평가
④ Label을 제거

### 59.

검증셋 접근에서 학습은 주로 어디에서 수행하는가?

① 훈련셋
② 검증셋
③ 테스트셋만
④ 전체 데이터와 무관

### 60. ★★

검증셋 접근의 한계로 옳은 것은?

① 어떤 표본이 어느 셋에 들어가느냐에 따라 추정치가 가변적일 수 있다
② 항상 계산량이 무한대다
③ 훈련 데이터를 전혀 사용하지 않는다
④ 모델 선택이 불가능하다

### 61.

검증셋 접근이 전체 데이터로 학습한 모델의 테스트 오류를 다소 크게 추정할 수 있는 이유는?

① 학습에 전체가 아닌 일부 데이터만 사용하기 때문
② 검증셋이 항상 너무 크기 때문
③ MSE를 사용하기 때문
④ Label이 범주형이기 때문

### 62.

K-겹 교차검증의 설명으로 옳은 것은?

① 데이터를 K개 폴드로 나누고 각 폴드를 한 번씩 검증에 사용
② K개 모델을 동시에 합쳐 하나의 Label을 만든다
③ 항상 K=1이다
④ 검증 데이터를 사용하지 않는다

### 63. ★★

K-fold에서 한 번의 반복 시 사용하는 구성은?

① 1개 폴드 검증, 나머지 K-1개 폴드 훈련
② K개 모두 검증
③ 1개 훈련, 나머지 모두 삭제
④ 전체를 훈련과 검증에 동시에 사용

### 64. ★★★

K-fold 교차검증의 최종 오류 추정은 일반적으로?

① 각 반복의 검증 오류를 평균
② 가장 큰 오류 하나만 사용
③ 훈련 오류만 사용
④ 첫 번째 폴드 오류만 사용

### 65.

K=n인 교차검증을 무엇이라 하는가?

① Leave-One-Out Cross-Validation
② Hold-out
③ K-means
④ Hierarchical Clustering

### 66. ★★

LOOCV에서 한 번의 반복 시 검증셋 크기는?

① 1
② 2
③ K/2
④ n-1

### 67.

LOOCV와 10-fold CV 비교로 강의에서 설명한 내용은?

① LOOCV는 연산량이 많아 학습 시간이 오래 걸릴 수 있다
② 10-fold는 검증을 전혀 하지 않는다
③ LOOCV는 데이터 하나만 학습한다
④ 둘은 항상 정확히 같은 결과를 낸다

### 68.

비지도학습(Unsupervised Learning)의 정의로 가장 적절한 것은?

① Label 없이 데이터의 구조·패턴·집단을 찾는 학습
② 정답 Label을 이용한 예측 학습
③ 테스트셋만 사용하는 학습
④ 회귀만 수행하는 학습

### 69. ★★

비지도학습의 대표 과제로 강의에서 제시되지 않은 것은?

① 군집화
② 차원축소
③ 밀도추정/이상치 탐지
④ 정답 Label을 이용한 지도 분류

### 70. ★★★

클러스터링(Clustering)의 핵심 목표는?

① 집단 내부는 서로 유사하고 집단 사이는 서로 다르게 데이터를 분할
② 정답 Label을 예측
③ 연속값만 예측
④ 모든 데이터를 한 군집으로 강제
