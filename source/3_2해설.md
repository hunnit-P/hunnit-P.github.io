# 3_2 이미지 파운데이션 모델 문제은행 해설

### 1. ②

파운데이션 모델은 대규모 데이터로 사전학습한 뒤 다양한 문제와 작업에 범용적으로 빠르게 적용할 수 있는 기반 AI 모델이다. ①과 ④는 특정 태스크나 학습 데이터에 지나치게 제한된 설명이고, ③은 강의자료에서 현실적이지 않은 이상적 검색 방식에 가깝다.

### 2. ②

강의자료는 현실적인 학습을 데이터를 패턴화하여 압축하는 과정으로 설명한다. 이 과정에서 모델은 유사점과 차이를 파악하고 표현을 학습한다.

### 3. ①

Representation Learning은 데이터의 패턴과 표현을 학습해 새로운 데이터에도 일반화할 수 있도록 하는 관점이다.

### 4. ④

파운데이션 모델은 오히려 한정되지 않은 다양한 출력과 작업에 활용할 수 있는 범용성이 특징이다.

### 5. ②

파운데이션 모델 패러다임은 거대 모델과 대규모 데이터 사전학습을 바탕으로 새로운 작업에 빠르게 적응하는 방식이다.

### 6. ②

강의자료의 개발 프로세스는 Data Creation, Data Curation, Training, Adaptation, Deployment 순으로 제시된다.

### 7. ③

Zero-shot은 추가 학습 없이 모델이 사전학습 과정에서 얻은 배경지식을 이용해 처음 보는 문제를 바로 수행하는 방식이다.

### 8. ①

Few-shot은 소수의 예시를 제공해 모델이 작업 형식을 파악하고 수행하도록 하는 방식이다.

### 9. ②

Fine-tuning은 특정 태스크에 맞춰 추가 학습하며 모델 자체의 가중치를 변경할 수 있다.

### 10. ②

과거에는 태스크별로 새 모델을 학습하는 비중이 컸지만, 파운데이션 모델 시대에는 이미 잘 학습된 모델을 어떻게 활용하고 적응시키는지가 중요해졌다.

### 11. ③

강의자료는 인간의 cognition을 perception과 higher cognitive processes의 결합으로 제시한다.

### 12. ②

언어와 사고만으로 현실의 시각적 정보를 모두 이해하기는 어렵다. 따라서 시각 등 추가 modality를 연결하는 멀티모달 접근이 필요하다.

### 13. ①

VLM은 이미지 인코더가 만든 시각 특징을 언어모델이 활용할 수 있도록 연결해 이미지와 언어를 함께 처리한다.

### 14. ②

GPT-4 계열 사례는 자연어에 한정된 모델에서 더 나아가 이미지, 문서, 음성 등 멀티모달 데이터를 처리하는 능력을 보여준다.

### 15. ①

Sketch-to-web 사례는 손으로 그린 UI 스케치를 이해하고 이를 실제 HTML/JS 코드 및 웹페이지로 연결하는 멀티모달 능력을 보여준다.

### 16. ①

이미지 인코더는 픽셀 입력을 모델이 처리하기 좋은 시각 특징 또는 임베딩으로 변환한다.

### 17. ②

시각 인코더의 출력과 언어모델의 입력 표현은 형식과 공간이 다를 수 있으므로 projection/connector가 이를 연결한다.

### 18. ②

멀티모달은 이미지, 텍스트, 음성 등 서로 다른 정보 양식을 함께 처리하는 것을 뜻한다.

### 19. ②

sVLM은 모바일·엣지처럼 메모리와 연산 자원이 제한된 환경에서도 멀티모달 기능을 제공하려는 흐름이다.

### 20. ①

sLLM의 경량화 시도처럼 VLM에서도 모델을 작고 효율적으로 만들어 다양한 온디바이스 환경에서 실행하려는 시도가 이어진다.

### 21. ②

### 76.

기존 태스크별 딥러닝은 특정 문제마다 데이터를 준비하고 모델을 별도로 학습하는 방식의 비중이 컸다. 반면 파운데이션 모델은 대규모 데이터로 먼저 사전학습하여 넓은 기본 지식과 표현을 습득한 뒤 다양한 다운스트림 작업에 적용한다. 이 때문에 하나의 잘 학습된 모델을 여러 목적에 사용할 수 있는 범용성이 높고, Zero-shot, Few-shot, Fine-tuning, 프롬프트 등의 방식으로 새로운 작업에 빠르게 적응할 수 있다.

### 77.

Zero-shot은 별도의 추가 학습 예제 없이 사전학습에서 얻은 지식으로 바로 작업을 수행한다. Few-shot은 몇 개의 예시를 프롬프트 문맥 등에 제공해 작업 형식을 이해시키지만 일반적으로 모델 가중치를 직접 변경하는 추가 학습을 뜻하지는 않는다. Fine-tuning은 특정 태스크의 데이터를 사용해 모델을 추가 학습하며 모델 가중치를 변경한다. 따라서 추가 데이터와 가중치 변경의 정도가 Zero-shot → Few-shot → Fine-tuning 순으로 커진다고 이해할 수 있다.

### 78.

이미지 인코더는 입력 이미지의 픽셀 정보를 고차원의 시각 특징 또는 임베딩으로 변환한다. Projection/connector는 이 시각 특징을 언어모델이 사용할 수 있는 표현 공간이나 토큰 형식에 맞게 변환하고 연결한다. 언어모델은 변환된 시각 정보와 텍스트 토큰을 함께 받아 질문에 답하거나 캡션을 생성하는 등 최종 언어 출력을 만든다. SmolVLM 예시에서는 SigLIP이 Vision Encoder이며 그 뒤에 Modality projection + Pooling이 배치된다.

### 79.

sVLM은 모바일과 엣지처럼 메모리, 저장 공간, 연산량이 제한된 환경에서 VLM 기능을 제공하기 위해 중요하다. 모델 크기가 작을수록 다운로드와 저장 부담이 줄고, 추론에 필요한 RAM과 연산량도 줄어 실시간 실행에 유리하다. 양자화는 파라미터 정밀도를 8비트나 4비트 등으로 낮춰 파일 크기와 메모리 사용량을 줄이고 속도를 높일 수 있다. 다만 정밀도가 낮아지므로 일부 정확도나 출력 품질이 소폭 감소할 수 있다는 trade-off가 있다.

### 80.

영어 중심 토크나이저는 영어에서 자주 등장하는 문자열과 단어 조각을 효율적으로 vocabulary에 포함하는 반면 한국어처럼 구조와 형태가 다른 언어는 같은 의미를 표현해도 더 많은 서브워드 토큰으로 분해될 수 있다. 그러면 같은 컨텍스트 길이에서 실제 담을 수 있는 정보량이 줄어든다. 한국어 특화 토크나이저는 자주 사용되는 한국어 단위와 표현을 vocabulary에 추가하거나 재설계하여 토큰 수를 줄이고 컨텍스트 효율을 높일 수 있다.

### 81.

LMDeploy는 LLM/VLM의 효율적인 압축, 배포, 서빙을 지원한다. 지속적 배치, 병렬화, 고성능 CUDA 커널 등을 통해 추론 처리량을 높일 수 있고, 4비트 양자화 등으로 모델의 메모리 요구량과 추론 비용을 낮출 수 있다. 여러 머신과 GPU를 활용한 분산 서빙도 지원하며, 대화 이력의 반복 재처리를 줄이는 캐싱 등을 통해 대화형 추론도 효율화한다. 따라서 InternVL 같은 VLM을 오프라인 파이프라인 또는 API 서버 형태로 배포하는 데 활용할 수 있다.

### 82.

SAM은 클릭, 박스, 부분 마스크, 텍스트 등 사용자의 segmentation prompt를 받아 원하는 영역의 마스크를 추출하는 범용 분할 모델이다. Grounding DINO는 텍스트 입력을 이용해 이미지에서 해당 개념에 해당하는 객체를 탐지하고 주로 위치 박스를 제공한다. Grounded SAM은 Grounding DINO가 텍스트로 탐지한 객체의 박스를 SAM의 입력으로 전달하여 개별 객체를 정밀하게 분할한다. 따라서 자연어로 찾고 싶은 객체를 지정하면서 탐지와 분할을 한 파이프라인에서 수행할 수 있다.

### 83.

일반 이미지에서는 "왼쪽 물체", "창문 가까운 의자"처럼 자연어 지시가 여러 객체 중 어느 것을 가리키는지 모호할 수 있다. SoM은 이미지의 객체 또는 영역에 번호나 마크를 부여하여 언어모델이 특정 시각 요소를 명시적으로 참조할 수 있게 한다. 그 결과 객체 위치와 언어 지시의 대응이 쉬워지고 visual grounding 오류를 줄일 수 있다.

### 84.

영어 중심 토크나이저에서는 한국어가 동일한 의미를 표현하는 데 더 많은 토큰을 요구할 수 있어 토큰 정보 밀도가 낮아지고 컨텍스트 창을 비효율적으로 사용하게 된다. 한국어 특화 vocabulary와 토크나이저를 사용하면 자주 쓰이는 한국어 단위를 더 큰 의미 단위로 처리하여 토큰 길이를 줄일 수 있다. 여기에 한국어 텍스트와 이미지 데이터를 함께 학습한 sVLM을 사용하면 한국어 질의와 시각 정보의 연결도 강화할 수 있다. HyperCLOVAX-SEED-Vision-Instruct-3B와 Kanana-1.5-v-3b-instruct가 강의자료의 대표 사례다.

### 85.

기존 특정 태스크 전용 비전 모델은 정해진 클래스나 한정된 출력 구조에 강하게 묶일 수 있다. 이미지 파운데이션 모델은 방대한 데이터로 사전학습하여 더 높은 일반화 능력을 확보하고, 다양한 입력 프롬프트와 다운스트림 작업에 재사용할 수 있다. SAM은 다양한 프롬프트를 받아 범용적으로 영역을 분할하고, Grounding DINO는 자연어 텍스트로 다양한 객체를 탐지하며, Grounded SAM은 두 모델을 결합해 자연어 기반 탐지와 정밀 분할을 함께 수행한다. 이러한 조합은 하나의 고정된 태스크에 한정되지 않고 검색, 탐지, 분류, 분할 등 여러 응용으로 확장될 수 있다는 점에서 파운데이션 모델의 범용성을 보여준다.

### 시험 직전 요약

파운데이션 모델은 대규모 사전학습, 적응성, 범용성이 핵심이다. Zero-shot은 추가 학습 없음, Few-shot은 소수 예시 제공, Fine-tuning은 추가 학습으로 가중치 변경이다. VLM은 이미지 인코더와 언어모델을 projection/connector로 연결한다. sVLM은 모바일·엣지 실행을 위해 작고 효율적이며 양자화가 중요하다. 한국어에서는 영어 중심 토크나이저의 토큰 비효율을 주의한다. 이미지 파운데이션 모델에서는 SAM은 분할, Grounding DINO는 텍스트 기반 탐지, Grounded SAM은 탐지+분할 결합으로 기억한다.
