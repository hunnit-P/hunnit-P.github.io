## A. 파운데이션 모델과 거대 언어 모델

### 1.

파운데이션 모델의 설명으로 가장 적절한 것은?

① 특정 태스크 하나만 수행하도록 소규모 데이터로 학습된 모델\
② 대량의 데이터로 사전학습되어 다양한 작업에 범용적으로 활용 가능한 기반
모델\
③ 사람이 모든 정답을 직접 입력해야만 동작하는 모델\
④ 학습 없이 규칙만으로 동작하는 모델

### 2.

파운데이션 모델의 장점과 가장 관련 깊은 것은?

① 새로운 태스크마다 반드시 모델을 처음부터 다시 학습한다.\
② 자세한 설명이나 프롬프트만으로 새로운 작업에 활용할 수 있다.\
③ 데이터가 많아질수록 성능이 항상 감소한다.\
④ Transformer를 사용할 수 없다.

### 3.

강의자료에서 파운데이션 모델의 핵심 구성요소로 보기 어려운 것은?

① 빅데이터\
② 자가 학습(Self-supervised Learning)\
③ Attention 기반 Transformer\
④ 모든 데이터에 대한 수작업 정답 라벨

### 4.

Self-supervised Learning의 특징으로 맞는 것은?

① 반드시 사람이 모든 정답을 라벨링한다.\
② 데이터 자체에서 학습 신호를 구성할 수 있다.\
③ 모델의 파라미터를 학습하지 않는다.\
④ 추론 단계에서만 사용한다.

### 5.

다음 토큰 예측(Next Token Prediction)의 예로 가장 적절한 것은?

① "아까 밥 먹고"를 보고 다음 토큰 "왔어"를 예측\
② 이미지의 픽셀 수 계산\
③ 정답 레이블을 사람이 직접 입력\
④ 모델의 파라미터를 무작위로 삭제

### 6.

Attention의 설명으로 가장 적절한 것은?

① 입력 데이터에서 중요한 부분에 주의를 집중하는 메커니즘\
② 데이터베이스 정렬 알고리즘\
③ 학습률을 자동으로 0으로 만드는 기법\
④ 모든 토큰을 동일하게 제거하는 방법

### 7.

Transformer가 거대 언어 모델의 핵심 구조로 활용되는 이유와 가장 관련
깊은 것은?

① Attention을 기반으로 토큰 간 관계를 효과적으로 학습할 수 있기 때문\
② 순차 데이터 처리가 불가능하기 때문\
③ 파라미터를 전혀 사용하지 않기 때문\
④ 텍스트를 처리할 수 없기 때문

### 8.

GPT-2가 보여준 중요한 가능성은?

① 추가 태스크 학습 없이 텍스트 지시를 통해 새로운 태스크를 어느 정도
수행할 수 있음\
② 언어 모델의 크기가 커질수록 반드시 성능이 나빠짐\
③ 프롬프트는 모델 출력에 영향을 주지 않음\
④ 사전학습이 필요하지 않음

### 9.

Perplexity에 대한 설명으로 가장 적절한 것은?

① 언어 모델이 다음 토큰을 얼마나 잘 예측하는지 평가하는 지표 중 하나\
② 모델 파라미터 수만 세는 지표\
③ 이미지 해상도를 나타내는 지표\
④ GPU 개수를 나타내는 지표

### 10.

일반적으로 언어 모델의 Perplexity가 낮다는 것은 무엇을 의미하는가?

① 예측이 더 불확실하다.\
② 다음 토큰을 상대적으로 더 잘 예측한다.\
③ 파라미터가 반드시 적다.\
④ 학습 데이터가 없다.

### 11.

Scaling Law의 핵심 내용으로 가장 적절한 것은?

① 데이터, 모델 크기, 연산량 증가와 성능 향상 사이에 일정한 경향이
존재한다.\
② 모델을 작게 만들수록 언제나 성능이 좋아진다.\
③ 데이터가 많아지면 학습할 수 없다.\
④ 연산량은 모델 성능과 무관하다.

### 12.

강의자료에서 텍스트 파운데이션 모델의 특징으로 제시된 조합은?

① 더 많은 데이터, 큰 모델, 긴 학습\
② 더 적은 데이터, 작은 모델, 짧은 학습만\
③ 데이터 없이 규칙만 사용\
④ 지도학습만 사용

### 13.

Emergent Property(창발성)의 의미는?

① 모델 규모가 특정 수준을 넘으면서 이전에는 뚜렷하지 않던 능력이
나타나는 현상\
② 모델이 학습 도중 삭제되는 현상\
③ 모든 모델이 동일한 성능을 내는 현상\
④ 모델이 입력을 받지 못하는 현상

### 14.

창발성의 예로 강의자료에서 언급된 것은?

① In-Context Learning과 추론 능력\
② 이미지 크기 조절만\
③ 데이터베이스 조인\
④ 파일 압축

### 15.

In-Context Learning의 설명으로 맞는 것은?

① 모델 가중치를 반드시 업데이트해야 한다.\
② 프롬프트의 설명과 예시를 이용해 새로운 태스크를 수행한다.\
③ 모델을 처음부터 재학습한다.\
④ 학습 데이터를 삭제한다.

### 16.

Zero-shot prompting의 의미는?

① 예시 없이 지시만 제공\
② 예시 한 개 제공\
③ 예시 여러 개 제공\
④ 모델 전체를 fine-tuning

### 17.

One-shot prompting의 의미는?

① 예시 없이 지시만 제공\
② 예시 하나를 제공\
③ 수천 개의 학습 데이터를 제공\
④ 파라미터를 절반으로 제거

### 18.

Few-shot prompting의 의미는?

① 소수의 예시를 프롬프트에 제공\
② 예시를 절대 제공하지 않음\
③ 반드시 모델 가중치를 변경\
④ 토큰을 하나만 입력

### 19.

거대 언어 모델을 구분하는 절대적인 파라미터 수 기준이 존재한다고 보기
어려운 이유는?

① 기술 발전에 따라 규모 기준이 계속 변하기 때문\
② 모든 모델의 크기가 동일하기 때문\

④ LLM은 파라미터를 갖지 않기 때문

LLM이 일반적으로 학습되는 대표 방식은?

① 대규모 텍스트에서 다음 토큰 예측을 수행하는 Transformer 기반 사전학습\

## B. 지시 학습과 선호 학습

### 21.

사전학습된 언어 모델에 Instruction Tuning이 필요한 주된 이유는?

① 사용자의 지시를 더 잘 이해하고 따르도록 만들기 위해\
② 파라미터를 모두 삭제하기 위해\
③ 텍스트 생성을 불가능하게 하기 위해\
④ 모델을 이미지 분류기로만 만들기 위해

### 22.

Instruction Tuning에서 일반적으로 사용하는 데이터 형태는?

① 지시문과 그에 대한 적절한 응답의 쌍\
② 이미지 픽셀만\
③ 정답 없는 난수만\
④ GPU 온도 로그만

### 23.

Supervised Fine-Tuning(SFT)에 대한 설명으로 맞는 것은?

① 정답 예시를 이용해 지도 방식으로 모델을 추가 학습한다.\
② 사람의 선호를 전혀 사용할 수 없다.\
③ 모델 가중치를 변경하지 않는다.\
④ 오직 추론 단계에서만 수행한다.

### 24.

Instruction Tuning의 결과로 기대할 수 있는 것은?

① 다양한 자연어 지시를 따르는 능력 향상\
② 언어 이해 능력 완전 제거\
③ 모든 응답 길이 고정\
④ 토큰화 제거

### 25.

선호 학습(Preference Learning)의 목적과 가장 가까운 것은?

① 여러 가능한 응답 중 사람이 더 선호하는 응답을 생성하도록 모델을 정렬\
② 모델의 vocabulary를 1개로 줄임\
③ 모든 출력을 무작위화\
④ 사전학습 데이터를 삭제

### 26.

RLHF의 전체 이름은?

① Reinforcement Learning from Human Feedback\
② Recursive Learning from Hidden Features\
③ Random Language Human Function\
④ Representation Learning for High Frequency

### 27.

RLHF에서 인간 피드백이 활용되는 대표 방식은?

① 여러 모델 응답에 대한 사람의 선호 비교\
② GPU의 전력 소비만 측정\
③ 토큰을 무작위로 제거\
④ 모델 구조를 CNN으로 변경

### 28.

Reward Model의 역할로 가장 적절한 것은?

① 응답에 대한 인간 선호를 점수 형태로 근사\
② 입력 문장을 토큰화하지 못하게 함\
③ 모델 파라미터 수를 세기만 함\
④ 이미지를 생성

### 29.

RLHF에서 정책 모델을 학습하는 목적은?

① 보상 모델이 높은 점수를 주는, 인간 선호에 가까운 응답을 생성하도록
개선\
② 무조건 가장 긴 문장을 생성\
③ 모든 답변을 동일하게 생성\
④ 언어 능력을 제거

### 30.

DPO(Direct Preference Optimization)의 핵심 아이디어와 가장 가까운 것은?

① 선호/비선호 응답 쌍을 이용해 별도의 복잡한 RL 과정 없이 직접 정책을
최적화\
② 모델을 학습하지 않음\
③ 이미지만 이용\
④ 모든 선호 데이터를 무시

### 31.

Preference dataset에 포함될 수 있는 대표적인 정보는?

① 동일한 프롬프트에 대한 chosen 응답과 rejected 응답\
② 이미지의 RGB 값만\
③ 학습률 하나만\
④ 운영체제 버전만

### 32.

Alignment의 의미로 가장 적절한 것은?

① 모델의 행동을 인간의 의도, 선호, 가치 및 안전 요구에 더 잘 맞추는
과정\
② 모델의 파라미터를 모두 같은 값으로 만드는 과정\
③ 문장의 좌우 정렬\
④ 데이터 파일 이름 변경

### 33.

SFT와 Preference Learning의 차이로 가장 적절한 것은?

① SFT는 정답 예시를 모방하도록 학습하고, Preference Learning은 응답 간
선호 정보를 활용한다.\
② 두 방법은 완전히 동일하다.\
③ SFT는 텍스트를 사용할 수 없다.\
④ Preference Learning은 모델 출력을 사용하지 않는다.

### 34.

지시 학습 후 선호 학습을 추가하는 이유로 적절한 것은?

① 지시를 따르는 것뿐 아니라 더 도움이 되고 선호되는 응답을 만들기 위해\
② 다음 토큰 예측을 완전히 금지하기 위해\
③ 모든 답변을 한 단어로 제한하기 위해\
④ 모델을 학습 전 상태로 되돌리기 위해

### 35.

인간 선호 데이터의 한계로 볼 수 있는 것은?

① 평가자 간 선호가 다를 수 있다.\
② 언제나 객관적이고 완벽하다.\
③ 비용이 전혀 들지 않는다.\
④ 편향이 절대 없다.

## C. 추론과 디코딩

### 36.

LLM 추론에서 decoding이 의미하는 것은?

① 모델이 예측한 토큰 확률 분포에서 실제 출력 토큰을 선택해 문장을
생성하는 과정\
② 학습 데이터를 수집하는 과정\
③ 파라미터 초기화\
④ 모델을 압축 파일로 만드는 과정

### 37.

Greedy Decoding의 특징은?

① 매 시점 가장 확률이 높은 토큰을 선택\
② 모든 토큰을 동일 확률로 선택\
③ 항상 두 번째로 높은 토큰을 선택\
④ 모델을 재학습한 뒤 선택

### 38.

Greedy Decoding의 장점은?

① 구현이 단순하고 결정적이며 빠른 편이다.\
② 항상 가장 창의적인 결과를 보장한다.\
③ 모든 후보 문장을 탐색한다.\
④ 반드시 최적 문장 전체를 찾는다.

### 39.

Greedy Decoding의 한계는?

① 각 시점의 국소 최적 선택이 전체 시퀀스의 최적 결과를 보장하지 않는다.\
② 계산이 불가능하다.\
③ 확률을 사용하지 않는다.\
④ 한 토큰도 생성할 수 없다.

### 40.

Beam Search의 핵심 아이디어는?

① 여러 개의 유망한 후보 시퀀스를 동시에 유지하며 탐색\
② 후보를 항상 하나만 유지\
③ 모든 토큰을 무작위로 선택\
④ 모델 가중치를 변경

### 41.

Beam width가 커질 때 일반적으로 발생하는 현상은?

① 더 많은 후보를 탐색하지만 계산량도 증가한다.\
② 후보 수가 줄어든다.\
③ 모델 파라미터가 자동 삭제된다.\
④ 학습 데이터가 감소한다.

### 42.

Sampling 기반 디코딩의 특징은?

① 확률 분포를 바탕으로 토큰을 확률적으로 선택\
② 항상 최대 확률 토큰만 선택\
③ 확률 분포를 사용하지 않음\
④ 모델을 반드시 fine-tuning

### 43.

Temperature가 높아질수록 일반적으로 나타나는 효과는?

① 확률 분포가 상대적으로 평평해져 다양한 토큰이 선택될 가능성이 커진다.\
② 출력이 항상 동일해진다.\
③ vocabulary가 사라진다.\
④ 모델 파라미터가 증가한다.

### 44.

Temperature가 매우 낮아질수록 일반적으로 나타나는 효과는?

① 높은 확률의 토큰에 선택이 더 집중된다.\
② 완전히 무작위가 된다.\
③ 모델이 학습을 시작한다.\
④ 입력이 삭제된다.

### 45.

Top-k Sampling은 무엇인가?

① 확률이 높은 상위 k개 토큰만 후보로 제한해 샘플링\
② k개의 모델을 동시에 학습\
③ 입력의 처음 k개 토큰을 삭제\
④ 출력 길이를 반드시 k로 고정

### 46.

Top-p(Nucleus) Sampling은 무엇인가?

① 누적 확률이 p에 도달하는 최소 후보 집합에서 샘플링\
② 항상 p번째 토큰 선택\
③ 파라미터의 p%를 삭제\
④ 확률을 사용하지 않음

### 47.

① Temperature, top-k, top-p 등 decoding hyperparameter\
② 모델 파일명\
③ GPU 제조사\
④ 운영체제 배경화면

### 48.

Autoregressive generation의 특징은?

① 이전까지 생성한 토큰을 조건으로 다음 토큰을 반복적으로 생성\
② 모든 토큰을 입력과 무관하게 생성\
③ 출력 토큰을 한 번도 다시 사용하지 않음\
④ 언어 모델과 무관

### 49.

Stop token 또는 EOS token의 역할은?

③ 입력을 이미지로 변환한다.\
④ 파라미터를 초기화한다.

① 확률적으로 다음 토큰을 선택할 수 있기 때문\
② 모델이 매번 새로 학습되기 때문\
